# 拍板 Slate —— 文案转视频工作台

**粘贴一篇文案，自动产出一条能直接发布的视频。**

拍板 Slate 是一款 Windows 桌面软件：把要讲解的内容粘进去，AI 自动完成分镜、配音、画面渲染，产出 1080p mp4。支持 19 套画面风格、真实素材混剪、克隆你自己的声音。

> 本仓库只发布安装包，不包含源码。

## ✨ 它能做什么

- **文案 → 视频，全自动**：AI 写分镜 → 微软官方音色配音 → 浏览器逐帧渲染 → ffmpeg 合成
- **19 套画面风格**：手绘、科技、墨韵、深空星野、极光、蓝图…… 鼠标悬停即可预览
- **真实素材混剪**：自动检索 Pixabay / Coverr 免费图库，动画与实拍画面混合剪辑
- **克隆我的声音**：录 10~30 秒，生成专属配音音色
- **横竖屏双画幅**：16:9（B 站/西瓜）与 9:16（抖音/视频号）
- **在线更新**：程序自动检查新版本，一键升级，无需重新下载安装

## 📥 下载安装

1. 到本仓库的 [Releases（发行版）](../../releases) 页面，下载最新版本的 `Slate_v1.0.3.zip`
2. 解压到任意目录（建议非 C 盘，如 `D:\Slate\`）
3. 双击 `Slate.exe` 启动

**首次启动**：程序会自动下载运行组件（Node.js / ffmpeg / Chromium / 渲染引擎，全部走国内镜像，通常 3~8 分钟，只需一次），完成后自动打开使用手册。程序会把服务完全准备好后再打开浏览器，不会出现「无法访问」。

> 系统要求：Windows 10 / 11（64 位）。软件绿色免安装，不写注册表；卸载时删掉目录即可。

## 🚀 三步出片

1. **启动程序**：双击 `Slate.exe`，浏览器自动打开工作台
2. **粘贴文案**：左侧输入文案（建议 300~2000 字），选好风格、音色、画幅
3. **生成**：点「开始生成视频」。一条 2~3 分钟的视频，普通电脑约 5~15 分钟渲染完成，可直接播放或下载

## 🔑 需要准备的 API Key

| Key | 是否必填 | 注册地址 | 用途 |
|---|---|---|---|
| DeepSeek | **必填** | platform.deepseek.com | AI 写分镜（一条视频成本约几分钱） |
| Pixabay | 可选 | pixabay.com | 免费图库素材（主源） |
| Coverr | 可选 | coverr.co | 免费视频素材（补充源） |

所有 Key 只保存在你自己电脑的用户配置文件里，程序不上传任何服务器。详细注册步骤见程序内「使用手册」。

## 📂 生成文件在哪

| 内容 | 路径 |
|---|---|
| 成片（mp4） | `<数据目录>\output\<任务号>\` |
| 渲染工程 | `<数据目录>\projects\<任务号>\` |
| 数据目录默认 | 有 D 盘 → `D:\AutoVideoData`，否则用户目录（设置页可改） |

## 🔄 在线更新

程序每 24 小时自动检查新版本：非强制更新会显示顶部横幅，可稍后处理；重大修复会要求更新后继续使用。更新包经 SHA-256 校验，点「立即更新」后全自动完成替换与重启。

## ❓ 常见问题

- **杀软报毒**：打包程序个别杀软会误报，把安装目录加入白名单即可
- **渲染慢**：1080p 约 3~4 帧/秒，2 分钟视频约 10 分钟属正常
- **配音失败**：配音用微软在线语音，需联网；公司内网可能拦截，可换热点验证
- **端口占用**：工作台使用 8005 端口，关掉多余程序窗口重试
- **彻底卸载**：删除安装目录 + `%LOCALAPPDATA%\AutoVideo` + 产物数据目录，注册表零残留

更多问题请看程序内右上角「使用手册」。
